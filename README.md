# pomodoro-spotify

A tool to use the pomodoro method with your favorite spotify playlists. Play and pause automatically with the chosen timer. 

In love with the pomodoro method but tired of Lofi Playlists? With this tool, use your own playlists while working. 

## MVP
- Connect Spotify
- Launch a 45-minutes timer
- Pause Spotify at the end

## Out of scope
- Personalized timer
- Other music tools
